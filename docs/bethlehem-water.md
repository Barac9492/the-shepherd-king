# 베들레헴의 물: 엄폐 중심 잠입 검토본

독립 로컬 에피소드 `/bethlehem-water.html`. 사무엘하 23:13–17을 직접 풀어 쓴 이야기이며 특정 현대 번역의 연속 인용이 아니다. 플레이어는 세 용사 중 한 명이다. 다윗은 진영에서 기다리며, 세 용사가 가져온 물을 여호와께 부어 드린다. 순찰·잠입·지형·대사는 창작적 각색이다.

## 최신 변경
- 기본 시야 10m → 19m. 웅크려도 개방 지형에서는 92%(17.48m)를 유지한다. 귀환 시 정상 난이도 기본 시야는 20.52m로 강화된다.
- 파랑 순찰, 주황 의심/수색, 빨강 추격. 3D와 전술 지도가 같은 팔레트와 core sightPolygon을 쓴다. 면 불투명도 32–43%, 윤곽 96%. 지면 시야는 깊이 검사로 건물/인물을 뚫어 칠하지 않는다.
- 출발점의 실제 높은 돌담, 서쪽 낮은 돌담, 수풀 경로, 외곽 및 우물 고정 경계병. 낮은 담은 이동을 막고 웅크린 시야만 가린다. 수풀은 거리 제한 은폐이며 근접 발각은 남는다.
- 우물 반대편 경계병에게 같은 위치의 서 있는 플레이어는 보이고, 웅크린 플레이어는 우물 자체로 가려진다.
- 물을 다 길어도 누르고 있던 숨기 입력은 유지된다. 행동 입력만 해제하며, 일시정지/창 전환/재시작에서는 모든 입력을 해제한다.
- 시야·소리·의심·수색·추격, 마지막 목격 지점, 제한된 돌 유인, 안전 체크포인트, 난이도 선택. 경보만으로 원격 즉사하지 않고 근접+실제 LOS가 있어야 붙잡힌다.

## 조작
WASD/방향키 이동, Shift 누르고 웅크리기, Space 누르고 달리기, E 누르고 물 긷기/전하기, Q 돌 던지기, Escape 일시정지. 터치용 조이스틱과 해당 버튼도 제공한다. 동료 둘은 연출이며 발각 판정은 조작 중인 용사에게만 적용한다.

## 검증 범위
기준 로컬 커밋: `666defdb09f20bcd91dd254f42b5ee25a03af86e`. 현재 production/main과 동일하다는 주장이 아니다.
- 최신 에피소드/잠입/UI 테스트 36/36 통과. 관련 기존 지형·마을·인물 이동·모바일 입력 회귀 43/43 통과. 전체 CI 실행은 아니다.
- 독립 순수 입력 시뮬레이션: 시작 지연 0/4/8초에서 엄폐 경로 왕복과 엔딩 모두 완료, 발각 0/붙잡힘 0. 정상 순찰이 지나갈 때까지 실제로 기다린다.
- 노출 경로 검사: 중앙과 최외곽 질주가 0/4/8초 각각 붙잡힘(6/6). 모든 가능한 경로나 스피드런이 불가능하다는 증명은 아니다. 서쪽 수풀을 통과하는 일부 빠른 접근은 살아남을 수 있다.
- Aside 실제 브라우저: 조이스틱, Shift, E로 엄폐·대기→물 긷기→귀환→봉헌 엔딩 완료. 최종 발각 0/재시도 0. 읽기 전용 시야 질의만 보조했고 순간이동·시계 조작·디버그 완료는 사용하지 않았다. 대화 중 대기 시간이 있으므로 이 실행 시간을 성능/속도 기록으로 제시하지 않는다.
- 우물 위치에서 서 있는 상태 시야=true, 웅크린 상태=false 확인. 물 긷기 완료 직후 crouching=true 유지 확인.
- 이전 잠입 검토에서 390×844/844×390 CSS 뷰포트, 추격→수색→순찰, 붙잡힘/재시도, 일시정지, 재플레이 검증. 실제 휴대폰 터치와 지속 FPS는 미검증이다.
- 독립 읽기 전용 검토: 새 차단급 문제 없음. 한때 실패했던 완주 검사는 테스트 조종기가 1.25초 후 임의로 일어나 달리던 문제였다. 기존 순수 대기 경로의 독립 왕복 성공을 확인한 뒤 조종기를 복구했으며 통과 기준은 낮추지 않았다.

## 구현·아트·출시 경계
기존 vendored Three.js 사용. 외부 AI 런타임, 계정, 진행 저장/랭킹 기능 없음. 로컬 진단은 data-state와 읽기 전용 bethlehemInspect.sightAt이며 게임 상태를 변경하는 API를 노출하지 않는다.

절차적 환경과 기존 warrior-refined.glb를 별도 로컬 잠입 검토본에서 재사용한다. GLB 불러오기/자세 보정 실패 시 기존 절차적 인물로 폴백한다. MakeHuman CC0 얼굴·손 등 출처는 assets/bethlehem-art/PROVENANCE.md에 있다. 해당 문서는 이전 독립 아트 검토의 상태를 기록하며, 아트 최종 승인은 여전히 FAIL이다. 인물 하체·옷 접합·드레이프는 미달이고 고급 그래픽 완성이라는 주장이 아니다.

기존 게임/메인 메뉴/API/랭킹/서버/설정은 변경하지 않았다. 커밋·push·PR·merge·배포·유료 호출 없음. 상태: **VERIFIED LOCALLY (잠입 기능 범위)**. 재미·인물 시각 품질·실기기·지속 FPS·최신 main 통합·공개 출시는 별도 미승인이다.

소스 묶음은 위 기준 저장소에 추가하는 파일 묶음이다. 전체 원본 게임이나 독립 설치 프로그램이 아니며 기존 vendor가 필요하다. 로컬 미리보기 서버는 영구 배포가 아니다.

## 2026-10-07 배포 요청과 감사 결과

위의 로컬 전용·미승인 표기는 이전 검토 시점의 기록이다. 이후 사용자는 아래 감사 결과를 전달받은 뒤 현재 버전의 배포를 명시적으로 요청했다. 이번 추가는 `/bethlehem-water.html` 및 전용 모듈·인물 자산·테스트에 한정하며 기존 메인 메뉴, 게임, API, 랭킹, DB, 서버 및 배포 설정을 수정하지 않는다. 런타임은 감사본과 동일하며 다음 문제를 수정한 버전이 아니다.

- 보통 난이도 실제 브라우저에서 웅크리기·돌·순찰 대기·재시도 없이 37.45초 만에 완주했다. 발각 3회, 붙잡힘 0회이며 추격 중에도 엔딩이 시작된다. 수풀을 지나므로 물리적 은폐가 전혀 없는 경로라는 뜻은 아니다.
- Escape를 계속 누를 때 키 반복 입력이 일시정지를 다시 해제한다.
- 새 소리를 조사한 뒤 이전 `_searchTarget`으로 되돌아가는 AI 상태 전이가 격리 재현되었다.
- 시야 도형은 수풀의 추가 감지 거리 감소까지 표현하지 않는 최대 잠재 시야다.
- 기존 79개 scoped 검사가 통과해도 위 문제는 검출되지 않는다. 전체 경로의 질주 완주와 에피소드 자체 키 반복 검사가 필요하다.

배포 승인은 위 알려진 제한을 없애거나 인물 아트·재미·실제 휴대폰·지속 FPS의 승인을 뜻하지 않는다. 배포 통합 기준은 최신 main `b883054`이며 기존 Downfall 랭킹 변경을 보존한다. 이번 패키지는 실제 런타임에 필요한 `warrior-refined.glb`만 포함하며 아트 실험용 중간 GLB와 진단 HTML은 제외한다. 공개 경로는 `/bethlehem-water.html`이며 메인 메뉴에는 추가하지 않는다.
