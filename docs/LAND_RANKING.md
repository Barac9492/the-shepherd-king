# 다윗의 땅 · 막별 TOP 10

## 범위

다윗의 땅 허브와 각 막 시작 화면, 플레이 HUD에서 순위표를 열 수 있다. 일반 플레이와 별개로 `랭킹 도전`을 눌러 시작한 새 기록만 제출한다. 기존 localStorage 기록은 소급 등록하지 않는다.

- 1막 아둘람, 2막 헤렛·그일라·엔게디, 3막 시글락: 함께한 인원 내림차순.
- 4막 다윗성: 성벽과 집을 완성한 시간 오름차순, 0.1초 단위.
- 5막 성전 준비: 준비율 내림차순.
- 막마다 상위 10개 **기록**. 동일 이니셜의 여러 기록이 있을 수 있다. 동점은 공동 순위이며 먼저 제출된 기록이 먼저 남는다.
- 랭킹은 동일한 시드 7과 기본 인원(2막 240, 3막 400, 4막 470)으로 시작한다. 일반 모드의 이전 막 인원을 이어받지 않는다. 일반 플레이는 종전대로 유지한다.
- 영문 이니셜 3자와 매번 해제 상태인 공개 동의를 거쳐야 게시한다. 열람에는 동의가 필요 없다. 본명·이메일·계정을 요구하지 않는다.

## 검증과 한계

서버는 다섯 막의 기존 순수 로직으로 플레이 입력을 다시 실행한다. 점수 숫자나 과거 로컬 기록은 받지 않는다. 실제 프레임 dt, 이동 속도(5막 노화 포함), 정적 지형과 천막·성벽 충돌, 장면 전환·스크립트 이동의 순서, 엔딩 도달을 확인하고 서버가 점수를 계산한다. 최대 30분, 108,000개 입력, HTTP 4MiB(클라이언트는 여유를 둔 3.8MB) 제한. 한도 초과 시 게임은 계속되지만 해당 기록 등록은 중단한다.

**사람이 직접 플레이했다는 증명은 아니다.** 봇 입력을 구별하지 않는다. 천막의 생성·철거·화재와 완성된 성벽의 점유 지연까지 재현한다. 기기별 프레임 dt가 같도록 강제하지 않는다. 점수는 신앙이나 성경 이해도의 척도가 아니다.

공개 API는 순위·이니셜·점수만 반환한다. 원본 입력은 보관하지 않고 재실행/해시에만 쓴다. 임시 시도는 2시간 후 만료되며 다음 요청 때 제한된 수로 정리한다. 공개 기록은 해당 막 상위 10개만 남긴다. 일별 HMAC IP 기반 요청 제한과 전역/테이블 상한을 적용하며 원 IP를 DB에 저장하지 않는다. 네트워크·날짜 변경 시 진행 기록이 확인되지 않을 수 있다.

## 로컬 검증

- 다섯 막의 완주 입력 및 실제 renderer recorder proxy의 캡처를 서버 재실행하여 결과 일치 확인.
- 점수 조작, NaN, 순간이동, 잘못된 장면 순서, 미완주, 범위 초과, 완성된 성벽 지름길 거절.
- 실제 PGlite SQL로 막 분리·정렬·동점·권한·동의·중복 재시도·시각 검증·저장 상한 확인.
- 브라우저에서 허브/막별 화면, 도전 발급/재시작, 빈 순위표, 0점 비등록, 기본 해제된 동의, 342명 로컬 테스트 기록 제출/순위 반영 확인. 테스트 기록은 운영에 게시하지 않았다.
- 320×568 iframe에서 실제 모달 배치와 기존 역할 표시/HUD 버튼 비겹침 확인. 실제 휴대폰 또는 인간 재미 검토는 아님.
- 독립 검토 및 최종 테스트 수치는 릴리스 시 기록.

개발용 `scripts/serve-land-ranking.mjs`는 loopback 전용 폐기 가능한 PGlite 서버이다. LAND_FIXTURE_TRANSCRIPT 환경변수가 있을 때만 테스트 완주 UI/시각 보정 경로가 열린다. 해당 경로는 운영 API에 존재하지 않는다. 테스트 시각 보정은 순수 재생 입력의 UI 검증용이며 실제 소요 시간 검증의 증거가 아니다.
