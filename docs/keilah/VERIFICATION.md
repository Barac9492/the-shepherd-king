# 로컬 검증 결과

기준 main: `025cdaa911f9d46a747d4d286d5dc45950051f5d`. 완료 전 원격 main을 읽기 전용으로 재확인했으며 동일했다.

최종 플레이 규칙: 두 사람이 서로 손잡이를 작동해 첫 통과를 돕고, 확보한 양쪽 통로로 나뉘어 구출한다. 가족은 한 팀씩 남문까지 인솔한다. 두 사람 모두 통로 확보와 구출에 참여하고 가족 네 팀이 도착한 뒤 두 사람 모두 탈출해야 서버가 완주를 기록한다.

모든 최종 실행 프로세스 exit 0. 핵심/스토리 실행의 총 320개는 기존 311개와 당시 그일라 테스트 9개였고, 이후 다른 두 팀의 순위 경쟁 테스트를 추가해 그일라 10개를 별도로 재실행했다.

그일라 브라우저는 390px와 320px의 **독립 컨텍스트**에서 실제 서버 시간을 사용했다. 최종 완주 **207,474.740084ms (3분 27.5초 표시)**. 양쪽 구역에서 동시에 가족을 인솔하는 상태, 두 번의 남문 도착, 두 사람 모두 탈출하기 전 미완료 상태를 확인했다. 같은 서버의 다른 팀 기록과 함께 TOP 10에서 확인했다. 테스트가 시간을 가속하거나 완주 상태/기록을 직접 쓰지 않았다.

브라우저 검증에는 1280px 진입 화면, 터치 및 키보드, 중복 방 생성 클릭, 코드 초대, 세 번째 입장 거부, 준비 취소/시작, 나가기 취소, 새로고침 자리 복구, 네트워크 끊김 후 연습 전환과 복구, 재도전 준비, 명시적 나가기와 상대 종료, 재입장, 메뉴 복귀 후 폴링 중단, 브라우저 뒤로 가기, 오프라인 나가기가 포함된다. pageerror는 없었다.

서비스/API 검증에는 첫 통과 때 동료 손잡이 필요/중간 해제 시 입구 복귀, 구출 시간과 한 가족씩 인솔, 두 탈출 조건, 재전송/이전 run/sequence gap, 다른 방 토큰 거부, 임의 점수·시간·이동 거부, origin/JSON 크기/스키마 제한, 연결 8초·60초, 방 만료·용량, 서버 지연 시 순위 제외, 서로 다른 두 팀의 동일 지도 순위가 포함된다.

## 발견 후 수정한 문제

- 초기 지도는 한 동료의 대기 시간이 길었다. 함께 확보한 통로를 유지하고 양쪽 동시 구출/한 가족씩 인솔하도록 변경한 뒤 실제 시간 완주를 다시 검증했다.
- 모바일 설명 영역을 접는 과정에서 나가기 버튼도 가려졌다. 진행 중 버튼을 상단으로 이동하고, 최종 전체 브라우저 흐름을 다시 실행해 나가기·복구를 확인했다.
- 메뉴 테스트의 한 초기 실행은 서버 시작 전에 접속해 실패했다. 준비된 서버에서 재실행해 15개 전체 통과했다.

## 범위와 남은 작업

실제 휴대폰/OS 입력기, 서로 다른 Wi-Fi/이동통신 네트워크, 운영 부하·장애·영속 DB는 미검증이다. 탭별 capability는 실제 두 사람임을 증명하지 않으며 자동 플레이를 완전히 방지하지 않는다. 한국어 시제품으로, 메인 메뉴 진입 이름만 기존 언어 전환에 맞춰 표시한다.

기존 개인 게임의 API·서버 판정·Supabase migration·잠금 파일은 변경하지 않았다. 운영 점수/방/DB 쓰기, 원격 push, PR, 병합, 배포를 하지 않았다. 새 credential이나 DB migration은 로컬 시제품에 필요하지 않다. 운영에는 [구조 문서](ARCHITECTURE.md)의 지속 실행 서버 또는 원자적 DB 기반 동기화와 별도 승인·검증이 필요하다.
