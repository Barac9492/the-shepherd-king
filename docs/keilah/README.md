# 그일라 2인 구출전 실행과 리뷰

첫 화면의 **챌린지 → 그일라 2인 구출전**에서 시작한다. 같은 서버에 접속한 두 사람이 초대 코드로 한 방에 모이고, 각각 준비하면 판이 시작된다. 초반 손잡이 역할을 교대해 두 통로를 연 뒤 양쪽으로 갈라진다. 가족은 한 번에 한 팀씩 남문으로 인솔한다. 네 가족과 두 플레이어가 모두 도착하고 각각 탈출을 눌러야 기록이 인정된다.

게임은 사무엘상 23:1–13을 바탕으로 한 창작 설정이며 사울을 처치하지 않는다. 성경 본문을 정답/대사로 새로 창작하거나 현대 역본 전문을 복제하지 않았다.

## 시작

Node 22와 저장소의 잠금 파일 기준 의존성으로 실행한다.

```sh
npm ci --ignore-scripts
npm run dev:keilah
```

기본 주소: http://127.0.0.1:44936/keilah.html

서로 분리된 두 브라우저 프로필/시크릿 창으로 열고 한쪽에서 방을 만들면 다른 쪽이 코드를 입력할 수 있다. 같은 프로필의 탭 복제는 sessionStorage까지 복사할 수 있으므로 두 플레이어 테스트는 **독립 브라우저 컨텍스트**로 한다.

두 휴대폰이 같은 신뢰할 수 있는 Wi-Fi에 있을 때에는 서버 컴퓨터에서 다음처럼 실행하고, 두 기기 모두 `http://<컴퓨터의 사설 IPv4>:44936/keilah.html`을 연다. OS가 요청한다면 로컬 네트워크 접근이 필요하다. 인터넷 공개나 포트포워딩은 이 로컬 시제품 범위에 포함하지 않는다.

```sh
HOST=0.0.0.0 PORT=44936 npm run dev:keilah
```

휴대폰에서는 아래 큰 목적지 버튼을 누르면 서버가 이동을 진행한다. 지도에서도 이웃 장소를 선택할 수 있다. 키보드는 Tab/Shift+Tab으로 버튼을 이동하고 Enter/Space로 선택한다. 입력기·카메라·마이크·소리 재생 권한을 요청하지 않는다.

## 검증 실행

```sh
npm run test:keilah
# dev:keilah 서버가 켜진 별도 터미널에서
npm run test:keilah:browser
BASE_URL=http://127.0.0.1:44936 npm run test:menu
```

브라우저 스크립트의 기본 Chrome 경로는 macOS의 Google Chrome이다. 다른 환경은 `CHROME_PATH=/path/to/chrome`으로 지정한다. 전체 협동 브라우저 검증은 실제 서버 시간을 사용하므로 한 판의 3–5분과 복구 확인 시간이 필요하다.

기존 게임 검증은 원래 `npm test`, `test:dance`, `test:engedi`, `test:challenge`, `test:exploration`, `test:garden` 스크립트를 유지한다. 개인 랭킹 테스트는 해당 기존 스크립트의 격리 fixture/서버를 사용하며 새 로컬 서버가 운영 랭킹으로 프록시하지 않는다.

## 검증 범위와 한계

- 독립 390px/320px 브라우저의 동일 방·지도·서버 시계 및 동시 구출, 실제 시간 완주를 검증한다.
- 1280px 진입 화면과 키보드 준비, 두 자리 제한, 중복 클릭, 새로고침, 연결 중단/복구, 방 나가기/재입장을 검증한다.
- 단위/API 테스트에서 통로 협동, 가족 인솔, 두 사람 탈출, 별도 팀 순위, 임의 점수/시간/이동 거부, 방 격리, 만료·서버 지연을 검증한다.
- 실제 휴대폰, Wi-Fi 지연, 장시간 부하, 운영 장애 복구, 영속 DB, 세계 순위, 인증된 두 사람 판별은 검증 범위 밖이다.
- 방과 기록은 서버 메모리에만 있으며 재시작하면 사라진다. 실행 중 다른 팀과는 같은 지도 기록을 비교할 수 있다.

실제 캡처와 JSON은 `test-results/keilah/`에 저장한다. 구조와 운영 전 필요한 작업은 [ARCHITECTURE.md](ARCHITECTURE.md)를 참고한다. 이 프로토타입에는 운영 배포 승인이 적용되지 않으며 push/PR/병합/운영 DB 쓰기를 하지 않는다.
