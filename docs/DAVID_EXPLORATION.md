# 다윗과 산책하기

2026-10-03 사용자 승인 범위의 베들레헴 탐험 모드입니다. 기준 커밋은 `d1a538de8038ce3cf0be88169b46ec86cbb5ba01`입니다.

시작 화면의 **다윗과 산책하기**로 들어갑니다. 기존 들판·양우리·마을 우물·이새의 집 주변을 걷고 달릴 수 있습니다. 선택한 목적지는 방향 안내만 제공하며 이동을 강제하지 않습니다. 양에게 다가가 E/행동 버튼으로 한 마리와 함께 걷거나 쉬게 할 수 있고, 양우리와 우물에서 짧은 산책 메모를 읽을 수 있습니다. 메모는 성경 직접 인용이 아닙니다.

이새의 집 앞에서는 **1장 이야기 시작하기**를 명시적으로 눌러야 원래 1장이 처음부터 시작됩니다. 산책 중 사자·심부름꾼·기름부음은 자동 실행되지 않습니다. 이야기 중간 이탈/체크포인트 복귀는 지원하지 않습니다. 산책 자체는 장 진도, 온라인 점수, 위치나 발견 상태를 저장하지 않습니다.

**산책 안내**에서 조작법, 입구 복귀, 시점 초기화를 사용할 수 있습니다. 처음 화면으로 나가거나 원래 일시정지 메뉴를 쓸 수도 있습니다. PC WASD/방향키·Shift·드래그와 기존 터치 조이스틱·달리기·시점 입력을 재사용합니다. 길 안내 선택기를 키보드로 다룰 때는 다윗이 동시에 움직이지 않습니다.

## 구현 경계

- `src/david-exploration.js`: 페이지당 한 번 설치하는 어댑터. `CH1`의 기존 아트·지형·충돌·카메라를 재사용하며 `CH1.run()`을 호출하지 않습니다.
- 월드 build가 설치한 양 튜토리얼은 명시적으로 dispose하고 자동 추종을 끕니다. 산책 동행 양은 별도 `exploring` 상태이므로 양우리 집계에 포함되지 않습니다.
- 세션마다 updater 하나와 chapter cleanup 콜백 하나를 등록합니다. 반복 입장 때 DOM 이벤트나 벽시계 타이머를 추가하지 않습니다. 종료 시 입력·안내·동행·카메라·UI를 정리합니다.
- 이야기 함수 본문, 저장 함수, 장 목록, 기존 source-contract 해시, 온라인 도전·API·DB 코드는 변경하지 않습니다. 온라인 도전의 제자리 조준과 공통 코스는 그대로입니다.
- 진입은 준비된 타이틀에서만 가능합니다. 중복 진입과 다른 모드 도중의 진입을 차단합니다. 이야기/타이틀 전환은 기존 진입점을 통하며 fade 대기 전에 산책을 종료합니다.
- 기존 반경 104 경계와 경사/충돌을 유지합니다. 배경 건물의 실내·지붕·원경은 새 보행 구역이 아닙니다.

## 검증

로컬 검증 서버와 독립 headless Chrome만 사용했습니다. 운영 DB나 점수 등록은 테스트 대상이 아닙니다.

- 기존 비브라우저 회귀: **257 통과**.
- 산책 전용 브라우저 시나리오: **13 통과**, page error 0. 별도 진입, 무저장/도전 요청 없음, 걷기·달리기·시점, 선택기 입력 분리, 양 동행·집계 차단, 우물 관찰, 명시적 이야기 전환, 경계·입구 복귀, 일시정지·도움말·언어, 반복 정리, 도전 왕복, 터치 취소·회전, legacy 렌더링 포함.
- 양우리 입구에서 동쪽을 돌아 기존 마을길·우물·이새 집 앞으로 이어지는 12구간을 실제 `moveTo()` 충돌/경사 함수로 확인했습니다. 전체 경로 도달 성공입니다.
- 원래 10장 이야기의 assisted runtime 체크 **12 통과**.
- 11장 ‘나의 목자’: desktop, phone emulation, legacy **3 통과**.
- 기존 기본 브라우저 **8 통과**, 물맷돌 챌린지 **14 통과**.
- PC, 모바일 세로/가로 화면을 캡처해 확인했습니다. 안내창은 작은 가로 화면에서 스크롤되며 조이스틱을 가리지 않습니다.

반복 진입 검증은 이전 월드가 제거되고 세션이 dispose되며 updater/cleanup 수와 geometry 수가 누적되지 않는지 확인합니다. 기존 장 진도를 `6`으로 둔 독립 브라우저에서 산책·이야기 진입·도전 왕복·새로고침 후 그대로인지 확인했습니다. 신규 브라우저의 저장 키도 산책 후 `null`입니다.

## 검증 한계와 릴리스

보행 경로·이야기 테스트에는 위치 이동/상태 준비를 돕는 fixture가 있습니다. 실제 사람이 전체 이야기를 완주했다는 뜻이 아닙니다. 터치는 브라우저 에뮬레이션과 실제 Input 핸들러에 전달한 합성 포인터를 함께 검증했으며, 물리 휴대폰 멀티터치·발열·장시간 성능은 별도 실사용 확인 대상입니다.

사용자는 전체 회귀 통과를 조건으로 PR 공개·병합·운영 배포를 승인했습니다. 운영 반영 시 정확한 PR head SHA, GitHub CI, Vercel 배포 commit과 최종 도메인을 확인해야 합니다. DB 마이그레이션이나 온라인 점수 제출은 이 릴리스에 필요하지 않습니다. 되돌릴 때에는 이 프런트엔드 변경만 되돌리며 점수 데이터는 건드리지 않습니다.
